# Shop Admin Panel

Professional Shop Management System Admin Panel built with React, Tailwind CSS, and Vite.

## Features

- 📊 Dashboard with analytics
- 📦 Product management
- 🛒 Order management
- 👥 Customer management
- 🏷️ Category management
- 👤 User management
- ⚙️ Settings panel
- 📱 Fully responsive design
- 🎨 Modern UI with Tailwind CSS

## Tech Stack

- **React 18** - Frontend library
- **Tailwind CSS** - Styling framework
- **Vite** - Build tool
- **React Router** - Navigation
- **Lucide React** - Icons
- **React Hot Toast** - Notifications
